USD/KRW 선물환 매입 금액 추천 프로그램 개발 기획서
1. 기획 목적
회사는 매월 약 U$10,000,000 규모의 달러를 매입해야 하며, 환율 변동에 따라 회사 손익이 크게 영향을 받는다.
외환 실제 매입 업무는 기존처럼 외환 담당자가 은행과 직접 진행한다.
 본 시스템은 외환 거래를 직접 실행하지 않고, 매일 환율·금리·정치·경제·시장 동향을 분석하여 오늘 어느 만기물을 얼마만큼 매입하는 것이 적절한지 추천하는 역할만 수행한다.
즉, 이 시스템의 목적은 다음과 같다.
매일 환율 시장 상황을 자동 분석한다.
1개월물~5개월물 선물환 매입 필요액을 관리한다.
오늘 매입할 금액을 만기별로 추천한다.
추천 사유를 경영자가 이해하기 쉽게 설명한다.
실제 매입 여부와 최종 금액은 외환 담당자와 경영진이 결정한다.

4. 프로그램의 핵심 개념
이 시스템은 환율을 정확히 예측하는 프로그램이 아니다.
환율 예측은 불확실성이 크기 때문에, 이 프로그램은 다음 원칙으로 설계한다.
1) 예측보다 리스크 관리
“환율이 반드시 오른다” 또는 “반드시 내린다”가 아니라,
 현재 시장상황에서 달러를 사지 않았을 때 발생할 수 있는 손실 위험을 평가한다.
2) 한 번에 전량 매입하지 않음
매월 U$10,000,000을 한 번에 사는 방식은 특정일 환율에 모든 위험이 집중된다.
 따라서 1개월~5개월물로 분산하고, 매일 시장 상황에 따라 일부씩 매입하도록 추천한다.
3) 회사 손익 방어 우선
월 U$10,000,000 기준으로 환율이 10원 상승하면 약 1억 원의 원화 부담이 증가한다.
따라서 이 시스템은 환차익을 노리는 시스템이 아니라, 손익 악화를 방지하는 방어형 외환 관리 시스템이다.

def calculate_risk_score(market_data, company_exposure):
   fx_trend_score = score_fx_trend(market_data)
   us_rate_score = score_us_rates(market_data)
   krw_supply_score = score_krw_supply(market_data)
   global_risk_score = score_global_risk(market_data)
   volatility_score = score_volatility(market_data)
   exposure_score = score_unhedged_exposure(company_exposure)

   total_score = (
       fx_trend_score * 0.25
       + us_rate_score * 0.20
       + krw_supply_score * 0.15
       + global_risk_score * 0.15
       + volatility_score * 0.10
       + exposure_score * 0.15
   )

   return total_score
def recommend_purchase_amount(tenor, remaining_amount, risk_score):
   tenor_weight = {
       "1M": 1.20,
       "2M": 1.00,
       "3M": 0.80,
       "4M": 0.60,
       "5M": 0.50,
   }

   adjusted_score = risk_score * tenor_weight[tenor]

   if adjusted_score >= 80:
       ratio = 0.80
       grade = "강력매입"
   elif adjusted_score >= 65:
       ratio = 0.60
       grade = "매입권고"
   elif adjusted_score >= 45:
       ratio = 0.35
       grade = "부분매입"
   elif adjusted_score >= 30:
       ratio = 0.10
       grade = "소량매입"
   else:
       ratio = 0.00
       grade = "관망"

   recommended_amount = remaining_amount * ratio

   return recommended_amount, grade

3. 각 만기별로 오늘 얼마를 매입하는 것이 적절한가?
따라서 개발 방향은 다음과 같이 정리된다.
환율·금리·뉴스 데이터 수집
→ 시장 리스크 점수 계산
→ 만기별 잔여 매입금액 확인
→ 오늘의 추천 매입금액 산출
→ 추천 사유 작성
→ 외환 담당자가 실제 매입 후 결과 입력
→ 다음 추천에 반영
이렇게 만들면 회사는 매일 감으로 외환을 매입하지 않고, 일관된 기준과 데이터에 따라 선물환 매입 판단을 할 수 있는 체계를 갖게 된다.
